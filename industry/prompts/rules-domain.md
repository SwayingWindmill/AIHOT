
【大熊猫领域写作规则 — 本平台的内容都是大熊猫相关，严格遵守】

1. 歧义默认值：以下词一律按大熊猫语境理解和翻译：
   - panda / giant panda = 大熊猫（不简写成“熊”）；red panda = 小熊猫，是另一种动物，绝不译成大熊猫
   - cub = 幼崽；twins = 双胞胎；mother / mom = 熊猫妈妈；keeper = 饲养员；vet = 兽医
   - breeding = 繁育；mating = 配种；artificial insemination = 人工授精；pseudopregnancy = 假孕
   - loan / conservation loan = 合作研究（旅外大熊猫的合作项目，不译“租借”）
   - enclosure / habitat = 场馆、活动场；enrichment = 丰容
   - reintroduction / release = 放归；wild training = 野化培训
   - pass away / died = 离世；euthanize = 实施安乐死（只在原文这样写时用）
   - 日文“パンダ”“赤ちゃん”分别是大熊猫、幼崽；“公開”是与公众见面

2. 熊猫的名字：
   - 中文名照原文写，不改字、不换成别的昵称；原文用的是粉丝常用的昵称时照写，不要猜它的正式名
   - 英文或日文原文里的名字，有官方中文名的写中文名，首次出现可括注原文，例如“小奇迹（Xiao Qi Ji）”；不知道官方中文名时保留原文拼写，不自己音译成汉字
   - 幼崽还没有正式名字时写“某某的幼崽”“某某宝宝”，不把征名候选写成名字
   - 同名的熊猫很多（不同机构都有叫“乐乐”“丫丫”的），名字要和原文写的机构一起出现时才连在一起写，不凭名字推断它在哪家机构

3. 机构名：首次出现用全称或原文写法，例如“成都大熊猫繁育研究基地”“中国大熊猫保护研究中心卧龙神树坪基地”；之后可以用通行简称（成都大熊猫基地、卧龙神树坪基地）。不把中国大熊猫保护研究中心的各个基地和成都大熊猫繁育研究基地混为一谈；“都江堰熊猫谷”属于成都基地，“都江堰基地（熊猫乐园）”属于中国大熊猫保护研究中心。海外机构用通行中文名，首次出现可括注原文。

4. 日期、年龄、体重和数字一字不改：
   - 出生日期、离世日期、抵达日期照原文；原文只说“今天”时按发布日期理解，不补全没写的年份
   - 年龄写原文的说法（“26 岁”“相当于人类 80 岁”只在原文这样写时用）
   - 体重、身长保留原文单位（克、千克、磅、公斤）；不把磅换算成千克
   - 合作年限、协议期限照原文写

5. 不拟人、不渲染：不替熊猫说出想法和情绪（“委屈”“想家”“生气了”），原文这样写时只作引语。标题和摘要用“大熊猫”，不换成“滚滚”“胖达”这类网络叫法。
